# Reflection (100 words)

Building the virtual dog park taught me how HTML and CSS fit together. HTML holds
the structure and CSS holds the styling, so the happiness bar broke because its
width was fixed at 33% in CSS while JavaScript only changed the number beside it.
Both layers had to agree. I also learned to use AI as a fast first draft: give a
precise brief, ask it to commit after each round, then test in a real browser and
fix what it missed, like a crash before the first scan. AI writes code; I check
and own it.
